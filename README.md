# CP372 - Bulletin Board System

## Overview
A multithreaded client-server bulletin board system built in Java using TCP sockets, supporting concurrent users posting and managing shared messages.

---

## Key Features
- Multithreaded server handling concurrent clients
- Custom application-layer protocol
- Thread-safe operations using synchronization
- GUI client with persistent connections and async communication

---

## Technologies
Java, TCP Sockets, Multithreading
